Subset with fontTools to shipped UI text; locally hosted.

V4 ships a dedicated ~40 KB opening-screen subset (kaigong-title.woff2), and a broader game UI subset (kaigong-display.woff2). Both are generated from the same Ma Shan Zheng font; no external font request is needed at runtime.

Decree v4: Ma Shan Zheng full glyph coverage split by Unicode range; uncommon glyphs use LXGW WenKai v1.320 (SIL OFL), https://github.com/lxgw/LxgwWenKai/tree/v1.320. The legacy format-4 cmap overflow is omitted; complete format-12 cmap retained. All runtime fonts served locally.
