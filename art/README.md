# 开弓美术素材

正式游戏使用 WebP 图集与独立环境图。人物姿态、靶子、机关、收藏品分别渲染；背景中不预埋人物或靶子。

- `camp-autumn-v2.webp`：秋日军营。
- `camp-winter-v4.webp`：雪山边营，本项目生成的 1536×1024 场景。
- `camp-ceremony-v4.webp`：封帅演武场，本项目生成的 1536×1024 场景。
- 女弓手按新兵、朱甲、银甲分图集；男弓手与 NPC 使用原角色图集。
- `camp-props-v1.webp`、`mechanisms-v1.webp`、`relics-v1.webp`：靶子、机关、48 件藏品。

图集采样采用逐个源矩形和必要的轮廓遮罩，避免相邻姿态串入。人物动画是姿态切换、呼吸、放箭反冲与马步，不是完整骨骼动画。`tools/art-audit.html` 可检查全部人物姿态和藏品。

旧 PNG 和早期豆丁素材保留作历史源文件，部署脚本只复制 WebP。新增背景使用版本化文件名，避免旧缓存影响。
