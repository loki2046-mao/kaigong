# 6.6.4 国内统计可靠性修复

旧链路：浏览器 -> 国内 Caddy -> 海外 Pages -> D1。任何一次跨境超时都会使浏览器此次写入失败。

新链路：浏览器 -> 国内 Python 标准库服务 -> SQLite WAL 持久队列 -> 后台同步到原 D1。POST 落盘后返回 202；重复事件 ID 不重计。跨日补报保留原日期，接受最近七天，D1 去重行保留三十天。超过补报窗口的记录进入 error 状态，health.failed 显示，不静默当作同步成功。队列上限十万条；满队列返回 503 而不虚假确认。

公共统计读取最近一次成功同步的真实快照。快照超过 90 秒标记 stale；不存在快照则返回 503，不返回虚构的零。浏览器保存最近真实统计供网络故障时显示，附“待同步”；回网和定时自动重试。实时/累计口径不改。

管理员数据不做本地缓存；仍由海外服务验证访问码，因此跨境断网时管理员查询可能暂不可用。公开计数与游戏不等待管理员查询。

服务只监听 127.0.0.1:8799，systemd 非登录专用用户，数据目录 0700，不写 IP/访问码日志。Caddy 覆盖客户端 IP 限流头；POST Origin 白名单和请求大小验证。原有游戏静态资源在国内服务器，不依赖海外字体/CDN。

验证：129 项 Node 回归通过；Python 故障注入检查通过（断网本地确认<1秒、SQLite恢复、重复去重、后台重试、缓存延迟标记、私有数据不缓存、非法Origin拒绝）。未用这些测试冒充全国移动网络保证。

部署状态：海外 Worker/网页已发布；国内待用户执行 update.py，并做线上复核。服务器安全登录需要用户操作，未关闭或绕过。

检查：curl -s http://127.0.0.1:8799/health；systemctl status kaigong-stats；公共接口 GET /api/visits/stats。pending 应最终归零，failed 应为零。跨境短暂中断允许 pending 暂增；公共快照可能延迟约一分钟。
